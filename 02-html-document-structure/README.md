# HTML Document Structure

## Overview

A well-structured HTML document uses semantic elements to provide meaning and structure to the content. This improves accessibility, SEO, and maintainability.

## Semantic Elements

- `<header>`: Represents introductory content or navigational links.
- `<nav>`: Defines navigation links.
- `<main>`: Contains the main content of the document.
- `<section>`: Defines a section in a document.
- `<article>`: Represents a self-contained composition.
- `<aside>`: Defines content aside from the main content.
- `<footer>`: Represents footer content.

## Example Structure

```html
<!DOCTYPE html>
<html>
<head>
    <title>Page Title</title>
</head>
<body>
    <header>...</header>
    <nav>...</nav>
    <main>
        <section>...</section>
        <article>...</article>
    </main>
    <aside>...</aside>
    <footer>...</footer>
</body>
</html>
```

3. Include an aside for related content.
