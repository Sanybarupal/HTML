# HTML Headings

## Overview

Headings in HTML are used to define the structure and hierarchy of content on a web page. They range from `<h1>` (most important) to `<h6>` (least important).

## Heading Elements

- `<h1>`: Main heading, usually one per page.
- `<h2>`: Major sections.
- `<h3>` to `<h6>`: Subsections of decreasing importance.

## Best Practices

- Use headings in logical order (don't skip levels).
- `<h1>` should be unique and descriptive.
- Headings improve SEO and accessibility.

## Example

```html
<h1>Page Title</h1>
<h2>Section 1</h2>
<h3>Subsection 1.1</h3>
<h2>Section 2</h2>
```
