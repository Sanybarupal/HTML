# Images

## Overview

This lesson covers Images, an important aspect of HTML for creating structured and accessible web pages.

**Hinglish:** Ye lesson Images ko cover karta hai, jo HTML mein structured aur accessible web pages banane ke liye important hai.

## Key Concepts

- **img tag**: Used to embed images.
- **src attribute**: Specifies the image URL.
- **alt attribute**: Provides alternative text for accessibility.
- **width and height**: Control image dimensions.

**Hinglish:**
- **img tag**: Images embed karne ke liye use hota hai.
- **src attribute**: Image URL specify karta hai.
- **alt attribute**: Accessibility ke liye alternative text provide karta hai.
- **width aur height**: Image dimensions control karte hain.
