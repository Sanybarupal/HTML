Understanding the <main> Element

What is the <main> Element?

The <main> element specifies the main content of a document. It represents the dominant content of the <body> and should only appear once per page.

Key Point: The <main> element is semantically important for accessibility and SEO.

Basic Syntax

<main>
    <h1>Page Title</h1>
    <p>Main content goes here...</p>
</main>

Example 1: Simple Blog Post

The following structure shows a typical blog page with a header, navigation, main content, and footer. Comments in the code illustrate where the <main> sits and how the page is organized.

<!-- page structure for a basic blog -->
<body>
    <header>
        <h1>My Blog</h1>
        <nav>...</nav>   <!-- main site navigation -->
    </header>
    
    <main>                 <!-- primary content area -->
        <article>
            <h2>Blog Post Title</h2>
            <p>Blog post content...</p>
            <!-- each post would be an 
 inside main -->
        </article>
    </main>
    
    <footer>...</footer>  <!-- site footer with copyright, links, etc. -->
</body>

This layout ensures screen readers and search engines focus on the blog articles first.

Example 2: E-Commerce Product Page

On a product page, the <main> contains the product details. Notice how sections are used for logical grouping and accessible labeling.

<main>
    <section aria-labelledby="product-title">
        <h1 id="product-title">Product Name</h1>
        <img src="product.jpg" alt="Product image">
        <p>Price: $99.99</p>
        <button>Add to Cart</button>
    </section>
    
    <section>
        <h2>Product Description</h2>
        <p>Detailed description...</p>
    </section>
</main>

The aria-labelledby attribute helps assistive technologies understand the product section.

Example 3: News Site Homepage

A news website often has multiple featured stories; <main> holds those articles while navigation remains outside the main area.

<main>
    <h1>Top Stories</h1>
    <article>
        <h2>Story 1</h2>
        <p>Summary of story 1...</p>
    </article>
    <article>
        <h2>Story 2</h2>
        <p>Summary of story 2...</p>
    </article>
</main>

Using multiple <article> elements keeps the content modular and accessible.

Important Rules

  • ✓ Use only ONE <main> element per page
  • ✓ Place it as a direct child of <body>
  • ✓ Cannot nest inside <article>, <aside>, <footer>, <header>, or <nav>
  • ✓ Supports "Skip to main content" links for accessibility

Accessibility Best Practice

Always include a "Skip to main content" link at the beginning of your page:

<body>
    <a href="#main-content" class="skip-link">Skip to main content</a>
    <nav>...</nav>
    <main id="main-content">...</main>
</body>

Quick Facts

  • One per page maximum
  • Browser Support: All modern browsers
  • Semantic HTML5 element
  • Improves accessibility
  • Helps with SEO
