# HTML SVG

## Overview

SVG (Scalable Vector Graphics) allows for the creation of vector-based graphics directly in HTML.

**Hinglish:** SVG (Scalable Vector Graphics) HTML mein directly vector-based graphics banane ki permission deta hai.

## Key Concepts

- **SVG elements**: Shapes like circle, rect, polygon.
- **Attributes**: cx, cy, r for circles; x, y, width, height for rectangles.
- **Scalability**: Vector graphics that scale without losing quality.

**Hinglish:**
- **SVG elements**: Shapes jaise circle, rect, polygon.
- **Attributes**: Circles ke liye cx, cy, r; rectangles ke liye x, y, width, height.
- **Scalability**: Vector graphics jo quality lose kiye bina scale hote hain.
